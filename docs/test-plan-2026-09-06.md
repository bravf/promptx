## 判定与约束

- P1：核心流程不可用、数据损坏或可复现的严重边界问题。
- P2：功能异常、有可用替代路径，或明显影响发布和维护的缺陷。
- P3：低影响体验、文案或测试基础设施问题。
- 只对实际执行且断言成立的项目标记通过；不可执行项目标记未验证并说明条件。
- 测试期间不直接修复业务实现，必要时增加可复现的测试和证据。
- 不连接真实远端进行 Git 写入；Git 推送使用本地临时 bare 仓库。
