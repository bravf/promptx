- Claude、Codex、Kimi、Grok 共用工具摘要和详情；未知 ACP/MCP 工具保留通用输入输出。

## 本次实现

共享协议层 `toolDetails.js` 解析 Claude input/output、Codex 原生工具字段、Kimi arguments/output、ACP rawInput/rawOutput/content/locations。摘要不包含完整输入、输出、大 metadata 或 base64。

详情接口：`GET /api/v2/tasks/:taskId/tool-calls/detail`，参数包括 turnId、callId、epoch、section、cursor、transport、manifest。

- 按 taskId + turnId + callId 索引查询生命周期记录，不扫描整段会话。
- 按 seq 增量合并工具数据；Codex outputDelta 分片存储，完成快照覆盖累计输出，不重复相加。
- 命令、目录、输入参数、输出、退出码、耗时、写入内容、修改片段与原生 patch 分区。只显示实际存在的字段。
- 空结果、未提供结果、等待输出与失败分开；已结束轮次中没有终态的工具保持静态未知状态。
- 修复 Codex completed 事件中的非零退出、失败和取消状态，以及原生 function/custom tool 日志的结果导入。
- 修复 60ms 合并覆盖命令输入/丢输出增量的问题；终态立即 flush。
- 原地纠正历史内容时换 epoch，详情缓存和游标同时失效。

## 本地与 Relay 策略

| 项目 | 本地 | Relay |
| --- | --- | --- |
| 默认工具列表 | 两行摘要、路径 | 单行关键摘要 |
| 正文单次 JSON 文本预算 | 48 KiB | 12 KiB |
| 详情并发 | 4 | 2 |
| 可见详情更新窗口 | 200ms | 750ms |
| 首次请求 | 点击展开 | 点击展开 |

预算按 JSON 转义后的 UTF-8 字节计算，响应还有有界的 section/cursor 元数据。中文、emoji、控制符和超长单行安全分页，单次响应保持低于 128 KiB。工具呈现记录通常小于 2 KiB，并在摘要过大时依次缩减路径、命令、摘要和错误预览；完整内容保留在详情。

已读完输出通过 manifest + cursor 只取新增正文；尚有未读页时不后台下载后续正文。cursor 绑定工具身份、epoch、section、已读取前缀，允许纯追加，拒绝内容替换后拼接旧正文。

收起工具、隐藏标签、切换页面或卸载取消在途/排队请求，不启动后台轮询。缓存按会话、轮次、调用、epoch 和呈现版本隔离，客户端最多 32 项且 8 MiB；服务端最多 64 项且 32 MiB，超大项不常驻。

Relay 继续使用现有加密 HTTP 隧道和 gzip 协商；响应正文发送队列超过 256 KiB 时暂停，下降到 64 KiB 后恢复，支持取消和超时。控制帧不等待正文队列。

此次导入共读取 959 条工具记录：Claude 122、Codex 684、Kimi 25、Grok 128。抽查各 Provider 已有工具类型的详情接口，确认返回输入/结果、修改片段等；不在仓库记录用户会话正文或完整原生标识。

## 验证及边界

新增测试覆盖四 Provider 解析、未知工具、空/缺失结果、二进制省略、中文/emoji 大输出分页、追加/替换游标、工具身份隔离、缓存预算、请求取消、事件合并、Codex 原生日志结果和 Relay 背压。

浏览器测试覆盖桌面本地、手机加密 Relay：折叠零详情请求、原地展开、长输出继续加载、整个过程区销毁重建后缓存命中、无横向溢出。

以下仍属于后续优化，不作为本次完成项：

- 普通 Timeline 超长消息的分段引用和全局 128 KiB 硬预算。现有 Timeline 按完整轮次分页的软预算未改，避免本次工具详情改动影响正文完整性。
- 对 1 Mbps / 200ms RTT 下发送/停止 P95 的定量压力验收；当前完成实际加密 Relay 功能回归。
- Provider 输出的二进制资源独立历史下载端点、双栏 Diff。现有文件预览仍可从路径进入。

真实历史导入不等于四种 CLI 都执行了新任务；实时差异由针对性事件测试验证，不会为了测试重跑用户的历史工具。

## 工具详情着色与布局（2026-09-29）

- 桌面和手机共用按需高亮组件，复用现有 Shiki 代码预览；命令按 Shell、参数按 JSON、读写内容按文件扩展名高亮。
- 原生 patch 直接渲染；提供前后文本时生成有界逐行 Diff，显示红绿增删和行内变化，长上下文折叠。单边内容保持代码展示，不虚构行号。ACP 同时提供输入片段和 diff 时只展示一份修改。
- 保留 ANSI SGR 颜色，安全移除其他终端控制序列；输出 HTML 一律转义。搜索结果弱化行号，已知字面搜索词可标记，普通日志不猜测语言。
- 工作目录缩为一行，退出码和耗时合并为状态栏；删除重复的纯路径参数，有修改内容的成功调用不再提示“未提供执行结果”。
- 着色只处理已加载正文，不改变 Relay 传输方式。超过 64,000 字符、1,500 行或超长单行时降级为纯文本，保持复制和分页；异步着色在隐藏、收起或卸载后不再提交过期结果。
- 已通过全量单元测试、构建，以及桌面/手机加密 Relay 浏览器回归。浏览器覆盖原生与生成 Diff、ANSI、代码、状态栏、缓存及深色主题刷新恢复；另对真实 Claude 会话进行了命令与 Diff 视觉检查。

## 工具详情滚动与自动展开（2026-09-29）

- 工具详情不再限制正文高度或单独纵向滚动，由 Timeline 统一滚动。命令和日志默认自动换行；代码、JSON、Diff 默认保留行结构与横向滚动，可按块切换“自动换行”。
- 每块内容先展示最多 30 行或 6,000 字符。“展开更多已加载内容”逐步扩大本地显示范围，不产生请求；“加载更多”继续通过原分页接口获取正文。复制仍复制已加载的全部内容。
- 本地设置新增“执行过程 → 自动展开工具详情”，默认关闭，保存在当前浏览器，跨浏览器标签同步。开启后，展开执行过程时其中的工具详情默认展开，包括历史记录、Provider 导入记录和实时调用；已显示的工具也立即应用设置。折叠的过程区及隐藏页面不预取详情。
- Relay 不显示该设置，也不执行自动展开；即使浏览器存有开启偏好，仍然点击后才读取详情。
- 手动收起的工具不会因后续更新或过程区域重建而自动打开；任务结束时保留正在查看的工具详情。刷新页面后工具遵循自动展开设置，手动开合状态仅在当前会话视图生命周期内保留。

## Timeline 滚动跟随

- 跟随状态独立于瞬时底部距离。工具自动展开、正文加载、语法着色或容器尺寸变化时，通过 ResizeObserver 监听正文与视口，每帧合并一次底部定位；移除固定 3 秒的强制跟随窗口。
- 滚轮向上、触摸向下拖动、向上翻页及滚动条上移暂停跟随。回到底部按钮、End 键或手动向下滚到底恢复跟随；隐藏标签与后台页面不执行滚动，返回后按原状态恢复。
- 手动展开过程区、工具、Diff 上下文、更多正文或切换换行时暂停跟随，保持阅读位置。正文增高本身不视为用户离开底部，不产生额外请求。

## Claude 后台任务层级修正

- 实时消息通过工具调用 ID 和 `parent_tool_use_id` 关联父 Agent；支持任务开始通知与工具消息乱序。未知归属保持待核实，不按其他正在运行的轮次猜测。
- 历史同步扫描子 Agent 原生日志中的工具调用关系，修复已保存命令的父任务及发起轮次，包括此前错误绑定到自动续跑轮次的记录。关系摘要仅在 Daemon 内处理，不向 Relay 发送原始日志。
- 同次请求只有一个子任务入口，子 Agent 内部命令嵌套在对应 Agent 下，主 Agent 的命令保留在顶层。总完成数包含内部任务并显示说明；真正无法确认归属的记录仍独立保留。
- 用户反馈的 Claude 会话经正常同步恢复全部 23 条记录归属：5 个子 Agent、5 条主 Agent 命令和 13 条子 Agent 内部命令；保留所有状态与结果。
