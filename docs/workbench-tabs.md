# 标签工作台

桌面端使用全局标签布局，不同工作区的会话可以同时打开、排列和分屏。点击左栏会话会打开会话标签；再次点击同一会话会定位到已有标签。每个会话包含自己的 Timeline 和输入框。

- 文件浏览、Git Diff、会话详情、终端和设置均可作为标签打开。文件浏览和 Git Diff 标签内保持左侧列表、右侧预览，点击文件不会新增标签；Timeline 文件链接会定位到对应浏览标签。
- 从会话打开终端、文件、Diff 或详情时，新标签在该会话所在的分栏打开；已有标签仍直接定位复用。
- 每个分栏保留自己的当前标签，但全局只有一个操作焦点。焦点标签使用主题色和加粗，其他分栏当前标签保留选中背景、使用普通正文色。点击标签或内容区会切换焦点，不改变其他分栏显示的内容。
- 标签栏右侧的按钮可向右、向下拆分；标签的更多操作菜单支持左、右、上、下四个方向以及移至其他分区。
- 拖动标签到内容区域边缘可拆分，到中央可移至该分区，到其他标签前可调整顺序。
- 拖动分隔线可调整比例，聚焦分隔线后也可使用方向键。
- 关闭最后一个标签会收起对应分区。空分区可以单独关闭，整个工作台至少保留一个分区。
- 标签菜单中的“关闭其他标签”只关闭当前分栏内的其他标签，并切换到保留的标签；只有一个标签时该项不可用。
- 关闭会话标签不会取消正在执行的任务。关闭终端标签保留进程；终端内部的“结束进程”按钮仍会停止对应终端。
- 切换、移动标签时保留组件，因此输入草稿、附件和滚动位置保持不变。刷新后恢复标签、活动标签和分区布局。

全局布局保存在当前浏览器中，仅保存视图标识、文件路径和分区信息，不保存文件内容或 Relay 配对信息。不同浏览器的布局互不同步。旧版按工作区保存的标签会自动合并，保留原活动工作区的分屏布局。

工作区和会话列表成功加载后才恢复、清理并保存布局，临时加载失败不会覆盖已保存的标签。鼠标点击和键盘进入分栏都会同步全局焦点。

所有会话视图与独立 Diff 标签共享一条事件连接，各订阅使用独立游标恢复。可见 Diff 在工具执行结束、轮次结束或连接恢复时刷新列表和当前预览；隐藏时暂停订阅。Timeline 标签关闭后，仍可通过独立 Diff 标签跟进文件变化。

## H5

窄屏继续使用原来的会话页面、文件和详情抽屉、设置弹窗及返回历史，不展示工作台标签和分屏控件。切回宽屏时恢复桌面布局。手机端浏览和切换会话不会重新排列桌面标签。

## 验证

运行 `pnpm build`、`pnpm --filter @promptx/web test` 和 `pnpm test:e2e`。

浏览器回归覆盖多会话草稿、组合分屏、拖拽、跨分区移动、比例和布局恢复、跨工作区混合分屏、文件和 Diff 左右栏预览、关闭运行会话、设置主题、附件上传、发送与取消，以及 H5 的返回历史和预览。新增布局状态测试位于 `apps/web/src/lib/workbenchTabs.test.js`。
